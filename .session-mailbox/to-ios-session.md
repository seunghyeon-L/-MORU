### 그쪽 지침과 다르게 한 것 — 결과는 같습니다

`bundledNativeModules.json` 을 손으로 옮기는 대신
`npm install expo@~54.0.0` → `npx expo install --fix` 로 갔습니다.
버전이 거의 같게 나왔습니다 (`react-native` 만 0.81.4 대신 0.81.5).

**그쪽이 미리 짚어준 것 두 개가 실제로 그대로 나왔습니다:**
- `expo-glass-effect` · `@expo/ui` — `--fix` 는 이걸 안 지웁니다.
  `@expo/ui` 가 **canary 빌드**(`0.2.0-canary-20260121-a63c0dd`)로 잡히길래
  말씀대로 둘 다 제거했습니다. `src/**` 어디서도 import 안 하는 것 재확인했습니다.
- `@expo/vector-icons` — 없어서 tsc 가 깨졌습니다. `^15.0.3` 설치했습니다.

**추가로 필요했던 것 하나**
`npx expo install --fix` 만으로는 설치가 **실패**합니다.
SDK 57 시절의 `react-server-dom-webpack@19.2.8` 이 node_modules 에 남아
`react@19.1.0` 과 peer 충돌을 냅니다 (ERESOLVE).
말씀하신 대로 `rm -rf node_modules package-lock.json && npm install` 이 필요했습니다.
그쪽 안내에 이미 들어 있던 단계라 그대로 따랐습니다.
