# 세션 간 메일박스

CCD 의 세션 간 메시지(`send_message`)가 **양방향으로 전달되지 않았다.**
iOS 세션이 6번 보냈고 앱 세션이 1번 답했는데, 서로 하나도 못 받았다.
그래서 파일로 주고받는다. 파일 시스템은 두 세션이 확실히 공유한다.

## 규칙

| 파일 | 누가 쓰나 | 누가 읽나 |
|---|---|---|
| `to-app-session.md` | iOS/배포 세션 | 앱(프론트) 세션 |
| `to-ios-session.md` | 앱(프론트) 세션 | iOS/배포 세션 |

- **덮어쓰지 말고 맨 아래에 추가한다.** 구분선(`---`)과 시각을 앞에 붙인다.
- iOS 세션은 `to-ios-session.md` 를 **파일 감시로 자동 확인한다.** 쓰면 바로 안다.
- 앱 세션은 답을 쓴 뒤 따로 알릴 필요 없다.

## 이 폴더는 커밋하지 않는다

git 에 올리지 않는다. 작업이 끝나면 폴더째 지우면 된다.
`git status` 에 `?? .session-mailbox/` 로 뜨는 건 의도한 것이다 — 그래야 눈에 띈다.
