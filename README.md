# MORU

> 두려움 때문에 좁아진 식탁, 안심하고 다시 넓혀주는 AI 웰니스 파트너

반복적인 소화기 불편(IBS 등)을 겪는 사람이 **무엇을 못 먹는지가 아니라, 무엇을 다시 먹을 수 있는지**를 찾아가도록 돕는 앱입니다.

---

## 이 서비스가 하지 않는 것

MORU는 **질병을 진단하거나 치료하는 의료 서비스가 아닙니다.** 기록을 바탕으로 음식 선택과 자기관리를 돕는 웰니스 도구입니다.

설계 전반이 이 원칙 위에 서 있습니다.

| # | 원칙 |
|---|---|
| 1 | **판정하지 않는다** — "위험/유발" 단정 금지. 관찰된 패턴만 제시하고 교란 요인을 함께 보여준다 |
| 2 | **점수·게이지·연속기록 금지** — 제한을 보상하는 설계는 섭식장애 위험을 키운다 |
| 3 | **개인 허용량은 숫자가 아니라 등급으로** — 재현성이 개인 판단에 못 미친다 |
| 4 | **AI는 입력·출력에만. 판정은 결정론적 코드** — 경고 신호 판정에 AI 사용 금지 |

## 개발 시작하기

### 서버

```bash
cd server
cp .env.example .env     # 실제 값 입력
```

`.env` 에 들어갈 값은 팀 내부 채널로 공유합니다. **절대 커밋하지 마세요.**

### 주의

`.gitignore` 에 다음이 포함되어 있습니다. 임의로 해제하지 마세요.

| 대상 | 이유 |
|---|---|
| `.env`, `*.pem` | API 키 · 서버 접속 키 |
| `assets/refshots/` | App Store 스크린샷. **저작권 — 팀 내부 참고용** |
