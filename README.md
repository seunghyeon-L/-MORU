# MORU (모루)

음식으로 인한 불편함이나 음식 제한을 경험하는 사람들을 위한 모바일 웰니스 앱입니다.

> 프론트엔드 리포지토리: https://github.com/seunghyeon-L/-MORU

## 1. 프로젝트 소개

### MORU는 어떤 서비스인가요?

MORU는 식사·증상·컨디션을 기록하고 그 안의 반복되는 패턴을 이해함으로써, 불필요한 음식 제한을 줄이고 다시 편하게 먹을 수 있는 음식의 범위를 넓혀가도록 돕는 모바일 앱입니다.

의료 진단·치료 서비스가 아니며, AI는 진단이나 결정을 내리지 않고 사용자의 기록을 바탕으로 참고 정보와 선택지만 제공합니다.

### 어떤 문제를 해결하나요?

특정 음식에 불편함을 겪은 사용자는 원인을 명확히 알지 못한 채 막연히 여러 음식을 피하게 되는 경우가 많습니다. MORU는

- "무엇을 먹으면 안 되는가?"가 아니라
- **"어떤 상황에서 어떤 음식을 어느 정도까지 편하게 먹을 수 있는가?"**

를 사용자가 스스로 이해하도록 돕는 데 초점을 맞춥니다. 1회의 기록만으로 특정 음식을 원인으로 단정하지 않고, 수면·스트레스·컨디션·음주·식사량 등 여러 상황을 함께 고려해 참고 정보를 제공하며, 금지·명령형 표현 대신 중립적이고 제안적인 표현을 사용합니다.

## 2. 주요 기능

실제 구현된(화면 + API 연동 완료) 기능만 정리했습니다.

| 기능 | 설명 |
| --- | --- |
| **온보딩 / 안전 확인** | 알레르기, 회피 음식, 기저 질환, 증상 이력 등을 입력받아 초기 프로필을 구성 |
| **음식 사진 분석** | 카메라로 음식/원재료표를 촬영하면 재료를 식별(`/meals/identify-photo`)하고, 텍스트 메뉴 검색으로도 식별 가능(`/meals/identify`) |
| **AI와 대화** | 식별된 음식에 대해 AI와 대화하며 대체 레시피, 성분 조절, 개인화된 선택지를 참고 정보로 제안받음(`/chat/messages`) |
| **음식 기록** | 식사를 기록하고(`/meals`), 기록 직후 참고 정보·관찰 결과가 있으면 인사이트 카드로 확인(`/meals/{id}/insight`) |
| **증상 기록** | 식후 컨디션/증상을 기록(`/symptoms`)하고, 위험 신호가 감지되면 의료기관 안내 화면으로 연결 |
| **음식 추천 / 대체** | 특정 음식에 대한 대체 음식(`/foods/{id}/alternatives`), 메뉴 대체(`/foods/{id}/menu-alternatives`), 재료 대체(`/substitutions`), 레시피 상세(`/recipes/{id}`) 제공 및 저장 |
| **개인화된 패턴 분석** | 누적된 기록을 바탕으로 개인 패턴을 분석(`/patterns`). 데이터가 부족하면 확정적 판단 없이 대기 상태로 표시 |
| **음식 재도전(재도입)** | 한동안 피했던 음식을 소량부터 다시 시도하는 흐름(도전 제안 → 준비 → 시도 → 기록 → 결과 판정)을 단계별로 지원(`/challenges/*`) |
| **나의 식탁** | 재도전 결과, 저장한 레시피/추천을 모아보는 개인 아카이브(`/mytable`) |
| **홈 대시보드** | 사용자 상태에 따른 맞춤 카드(도전 제안 등)를 노출(`/home`) |

## 3. 기술 스택

이 프로젝트는 웹이 아닌 **React Native 기반 모바일 앱**으로, Expo 도구 체인 위에서 개발되었습니다.

- **React Native** 0.86 / **React** 19
- **TypeScript**
- **Expo** (Expo Router 기반 파일 시스템 라우팅, 타입 라우트)
- **주요 라이브러리**
  - `expo-router` — 화면 라우팅
  - `expo-image-picker` — 카메라 촬영 / 사진 접근
  - `expo-image` — 이미지 렌더링
  - `expo-glass-effect`, `expo-symbols` — iOS 스타일 UI 요소
  - `react-native-reanimated`, `react-native-gesture-handler` — 애니메이션 및 제스처
  - `react-native-safe-area-context`, `react-native-screens` — 네이티브 화면/세이프에어리어 처리
  - `@react-native-async-storage/async-storage` — 로컬 저장(디바이스 ID 등)
  - `react-native-web` — 웹 프리뷰 지원
- **스타일링**: React Native `StyleSheet` 기반 자체 테마 시스템 (`src/constants/theme.ts`) — Tailwind CSS는 사용하지 않음

### API 연동 방식

- 모든 네트워크 요청은 `src/services/apiClient.ts`의 공통 `apiRequest()` 함수를 통해서만 호출됩니다.
- 요청마다 사용자를 식별하는 `X-Device-Id` 헤더를 자동으로 첨부합니다(로그인 없이 디바이스 단위 식별).
- Base URL은 `.env`의 `EXPO_PUBLIC_API_BASE_URL` 값을 사용합니다.
- `src/services/api.ts`가 실제 데이터 접근 계층 역할을 하며, 백엔드 계약이 확정된 기능은 실 API를, 아직 미확정인 일부 화면은 `src/mock`의 임시 데이터를 반환하도록 분리되어 있습니다(화면 코드는 항상 `api.ts`만 참조).
- 사진 업로드(`/meals/identify-photo`)는 `multipart/form-data`로 전송됩니다.

## 4. 프로젝트 구조

```
moru/
├── src/
│   ├── app/                 # 화면 라우트 (Expo Router 파일 기반 라우팅)
│   │   ├── (tabs)/          # 하단 탭 (홈 / 기록 / 나의 식탁)
│   │   ├── onboarding/      # 온보딩·안전 확인 플로우
│   │   ├── food/            # 음식 기록·촬영·AI 채팅·대체안 플로우
│   │   ├── symptom/         # 증상 기록 플로우
│   │   ├── reintroduction/  # 음식 재도전(재도입) 플로우
│   │   └── analysis/        # 패턴 분석 화면
│   ├── components/          # 화면별 / 공통 / UI 컴포넌트
│   ├── hooks/                # 커스텀 훅 (useMoruData 등)
│   ├── services/             # API 클라이언트, API 함수, 디바이스 ID
│   ├── types/                 # 도메인별 타입 정의
│   ├── constants/             # 테마 · 스페이싱 등 디자인 토큰
│   └── mock/                  # 계약 미확정 화면용 임시 데이터
├── assets/                    # 아이콘, 이미지, 일러스트
├── app.json                   # Expo 앱 설정
└── package.json
```

## 5. 실행 방법

```bash
# 1. 의존성 설치
npm install

# 2. 환경 변수 설정 (.env)
EXPO_PUBLIC_API_BASE_URL=<백엔드 API base URL>

# 3. 개발 서버 실행
npm start
# 또는 특정 플랫폼으로 바로 실행
npm run android   # Android 에뮬레이터/기기
npm run ios       # iOS 시뮬레이터
npm run web       # 웹 프리뷰
```

Expo Go 앱 또는 시뮬레이터/에뮬레이터가 필요합니다.

## 6. 페이지 / 화면

| 플로우 | 화면 |
| --- | --- |
| 온보딩 | 안전 확인 → 알레르기/회피 음식 → 기저 질환 → 증상 이력 → 완료 |
| 홈 | 맞춤 카드 대시보드 |
| 음식 기록 | 검색/촬영 → 재료 확인·수정 → 기록 완료 → (있는 경우) 참고 정보 인사이트 |
| AI와 대화 | 채팅형 화면에서 대체 레시피 / 성분 조절 / 개인화 선택지 제안 |
| 음식 대체 | 대체 허브 → 메뉴 대체 / 재료 대체 / 레시피 상세 |
| 증상 기록 | 증상 선택 → 중증도 → 상세 → (위험 신호 시) 의료기관 안내 |
| 재도전 | 도전 제안 → 준비/설정 → 진행 → 결과 |
| 나의 식탁 | 저장한 레시피 · 재도전 결과 아카이브 |
| 패턴 분석 | 개인화된 식사-증상 패턴 요약 |
