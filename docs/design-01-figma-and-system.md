# 3. 앱 화면 19개

## 3.1 캔버스 배치 — 플로우 5구간

```
A. 진입·온보딩 (y=260)
   A1 서비스 소개 → B1 안전확인 → B1x 차단 → B2 알레르기 → B3 피하는음식 → B4 증상문진

B. 홈·음식확인 (y=1360)
   C 홈 → D1 입력방식 → D2 재료확인 → D3 참고정보+대체안 → D4 완료

C. 증상·분석 (y=2460)
   E1 증상기록 → E2 상황확인 → E3 패턴분석

D. 표적 도전 (y=3560)
   F1 제안상세 → F2 제한설정 → F3 진행 → F4 결과

E. 결과 (y=4660)
   G 나의 식탁
```

## 3.3 프로토타입 연결 23개

재생 버튼을 누르면 A1부터 끝까지 실제로 눌러볼 수 있음. 시작점은 A1.

```
A1 시작하기 → B1
B1 해당없어요 → B2  /  하나라도있어요 → B1x
B1x 이미확인했어요 → B2
B2 다음 → B3 → B4 → C
C 오늘먹은것확인 → D1  /  해볼래요 → F1  /  탭 기록 → E1  /  탭 나의식탁 → G
D1 사진찍기 → D2 → (확인) D3 → (기록하기/그냥먹을래요) D4 → (홈으로) C
E1 기록하기 → E2 → (기록마치기) E3 → (확인해볼래요) F1
F1 시작할게요 → F2 → F3 → (오늘했어요) F4 → (저장하기) G
```

## 3.4 인터랙션 주석 19개

각 화면 아래(y+868)에 점선 박스로 **"뭘 누르면 어떻게 되는지"** + ⚠️ 금지 사항이 붙어 있음.

예:
```
E3 패턴 분석
  자동 실행      증상 기록 완료 시 바로
  출력 4상태     반복패턴 / 후보병기 / 보류 / 설명안됨
  ⚠️ 계산        "4번 중 3번" 기술통계. 역치 역산 금지
  [확인해볼래요]  → F1 도전 제안
```

# 4. 일러스트 (2026-08-19 추가)

## 4.1 스타일 기준

레퍼런스(Cara Care · Finch)에서 가져온 **선 없이 면으로만 그린 파스텔 플랫** 스타일.

- 아웃라인 없음
- 둥근 유기적 형태 (잎·원·타원)
- 세이지가 주인공, 파스텔은 보조
- 배경 원 하나 + 주요 요소 2~3개 + 작은 점 2~3개

## 4.2 제작한 5종

피그마 앱 파일의 **`일러스트` 페이지**에 원본 보관. 화면에는 복제해서 배치.

| 일러스트 | 노드 ID | 배치된 화면 |
|---|---|---|
| 넓어지는 식탁 | 35:9 | A1 서비스 소개 |
| 새싹 | 35:23 | F1 도전 제안 |
| 빈 접시 | 35:33 | **미배치** (빈 화면용) |
| 잎 + 체크 | 37:2 | D4 기록 완료 |
| 감싸는 손 + 하트 | 37:11 | B1x 병원 안내 |

## 4.3 기술 메모

- 잎은 **회전을 쓰지 않고 방향별 베지어 패스**로 그림 (Figma의 `rotation`은 회전 기준점이 어긋나 배치가 틀어짐)
  - `ne` (우상향): `M 0 s C 0 s*0.44 s*0.44 0 s 0 C s s*0.56 s*0.56 s 0 s Z`
  - `nw` (좌상향): `M s s C s s*0.44 s*0.56 0 0 0 C 0 s*0.56 s*0.44 s s s Z`
- 하트: `M s*0.5 s C s*0.16 s*0.72 0 s*0.5 0 s*0.31 C 0 s*0.11 s*0.2 0 s*0.34 0 C s*0.43 0 s*0.5 s*0.06 s*0.5 s*0.13 C ... Z`

## 4.4 미결

- **F1의 새싹은 뺄지 검토 중.** 화면에 정보가 많은데 일러스트까지 얹으니 스크롤이 길어짐. 레퍼런스에서도 일러스트는 정보가 적은 화면에만 씀
- **빈 화면(기록 없음)을 새로 만들어야** 빈 접시 일러스트를 쓸 수 있음

# 6. 레퍼런스에서 가져올 것

## 6.1 색은 가져오지 않는다

MORU 세이지 그린은 확정 자산. 레퍼런스에서 가져올 것은 **구조·형태·배치**이지 색이 아님.

| | hex | 판정 |
|---|---|---|
| MORU | `#7E9F6E` | ✓ 확정 |
| Ate 오렌지 | `#F08708` | ✕ 식욕 자극 |
| Clue 레드 | `#E03335` | ✕ 경고 연상 |
| Cara Care 국제 틸 | `#00B4A8` | ✕ **정확히 "병원 앱" 색** |
| Cara Care DiGA 그린 | `#1FA856` | ✕ 채도 과함 |
| 토스 블루 | `#3182F6` | ✕ 금융 앱 인상 |
| 파스타 다크 | 어두운 배경 | ✕ 우리는 크림 확정 |

**참조할 것은 "색 배정 방식"** — 예: Clue가 기록에는 A계열, 추정에는 B계열을 쓰는 규칙. 우리는 세이지 채도 차이로 같은 효과.

## 7.1 중간에 고친 실수

| 실수 | 수정 |
|---|---|
| `createAutoLayout` 기본 fill이 안 지워져 흰 박스 72곳 | 전부 `fills=[]` |
