## 0. 이 설문이 답해야 하는 것

설문은 "궁금한 걸 다 묻는 것"이 아니라 **이미 내린 결정 중 틀리면 제품이 무너지는 것**을 겨냥해야 한다.
아래 7개 결정이 이 설문의 전부다. 여기에 안 걸리는 문항은 넣지 않는다.

| # | 검증할 결정 | 근거 문서 | 담당 섹션 |
|---|---|---|---|
| D1 | 진단명이 아니라 증상으로 타겟한다 | A-1 | §1, §5-5 |
| D2 | **사용자의 자가 귀인은 틀리다 (진범은 몇 끼 전)** | 명제 4, F-3 | **§2** ⭐ |
| D3 | 회피 도구가 아니라 확장 도구로 판다 | 명제 3 | §3, §5-1 |
| D4 | 사용자는 로깅을 오래 못 버틴다 (리텐션 벽) | E-1 | **§4** ⭐ |
| D5 | **핵심 엔진은 재도입 챌린지다** | E-2 | **§5-3** ⭐ |
| D6 | 한국 시장 고유 요인이 있다 | A-2 | §3, §7 |
| D7 | 돈을 낼 사람이 있다 | — | §6 |

### 세 문항만 남긴다면

예산·시간이 부족하면 **이 셋만 물어도 제품 성립 여부를 판단할 수 있다.**

1. **§2-2** — 사용자가 지목한 원인이 증상 발생 **몇 시간 전**이었나 → D2
2. **§4-2** — 과거 식단 기록을 **며칠** 지속했나 → D4
3. **§5-3** — **일부러 먹어보는 3일 챌린지**에 참여할 의향이 있나 → D5

3번이 특히 위험하다. 챌린지가 핵심 엔진(E-2)인데 사용자가 "일부러 아파지는 건 못 하겠다"고 하면 **모델링 전략 전체를 다시 짜야 한다.** 이건 지금 확인하는 게 훨씬 싸다.

## 1. 설계 원칙 (문항보다 먼저 정할 것)

### 1-1. 컨셉은 반드시 뒤에 노출한다 ⚠️

앱 컨셉을 먼저 보여주면 이후 모든 응답이 오염된다.
"몇 시간 전 음식이 원인일 수 있다"는 힌트를 주고 나서 자가 귀인을 물으면 §2가 통째로 무의미해진다.

```
❌ 앱 소개 → 증상/귀인 질문 → 구매의향
✅ 증상·귀인·현재 행동 (§1~§4)  →  [여기서 처음 컨셉 노출]  →  반응·가격 (§5~§6)
```

이건 본 문서 D-2의 **동시 측정 편향** 방어와 정확히 같은 원리다. 예측 변수를 결과보다 앞에 둔다.

### 1-2. 가설을 문항에 누설하지 않는다

- ❌ "몇 시간 전에 먹은 음식이 원인일 수 있다는 걸 아셨나요?"
- ✅ "그 원인이라고 생각하시는 것은 증상이 나타나기 **몇 시간 전**이었나요?"

첫 번째는 정답을 알려준다. 두 번째는 사용자의 실제 인식을 잰다.

### 1-3. 회상 창은 짧게

"지난 3개월간 몇 번"은 회상 편향으로 못 쓴다. **최근 2주**로 고정한다.
예외: 진단 이력, 저포드맵 시도 경험처럼 사건성이 뚜렷한 항목.

### 1-4. 의향보다 행동 증거

"쓰시겠어요?" "내시겠어요?"는 긍정 편향이 심하다. 대신 **이미 한 행동**을 묻는다.

| 약한 질문 | 강한 질문 |
|---|---|
| 이 앱 쓰시겠어요? | 식단 기록을 시도한 적 있나요? 며칠 갔나요? |
| 월 9,900원 내시겠어요? | 최근 6개월간 관련해 실제로 얼마 쓰셨나요? |

### 1-5. 금지 문구는 설문에도 적용

F-2의 금지 문구("예민하신 것", "심리적 요인")는 설문 문항·안내문에도 쓰지 않는다.
응답자가 소외감을 느끼면 이탈하고, 남은 표본이 편향된다.

### 1-6. 분량

**목표 6분 / 25~30문항.** 아래 전체 안은 45문항 규모라 그대로 돌리면 완주율이 무너진다.
§8의 우선순위표에서 **[핵심]** 만 먼저 돌리고, 반응이 좋으면 2차로 확장한다.

### 1-7. 법적 고지 ⚠️

건강 정보는 개인정보보호법상 **민감정보**다. 일반 개인정보 동의와 **별도 동의 항목**이 필요하다.
- 익명 수집을 기본으로 (이메일은 리워드 지급용으로만, 응답과 분리 저장)
- 수집 목적·보유 기간·파기 시점 명시
- **"본 설문은 의학적 진단이나 조언이 아닙니다"** 고지 필수

## 2. 문항 설계

### S. 스크리너

| # | 문항 | 형식 |
|---|---|---|
| S1 | 연령 | 만 나이 구간 |
| S2 | 성별 | 남/여/응답 안 함 |
| S3 | 최근 2주간 복통·복부 팽만·설사·변비 중 하나라도 겪은 날이 며칠입니까? | 0 / 1–2 / 3–5 / 6–9 / 10일 이상 |

> **S3=0 처리:** 종료하지 말고 **대조군으로 분리 수집**한다. 유병률 추정과 "증상 있는 사람만 보면 안 보이는 것"에 쓸 수 있다. 다만 이후 섹션은 건너뛴다.

---

### §1. 증상 실태 — D1

**1-1.** 최근 2주간 증상이 있었던 날 수 *(S3과 중복이면 생략)*

**1-2. 증상 종류** *(복수 선택)* — **C-5의 통증 경로 분리가 사용자에게 구분되는지 검증**

- 배가 빵빵하게 부풀거나 눌리는 느낌 (팽만)
- 쥐어짜듯 아픔 (크램프)
- 갑자기 화장실에 가야 할 것 같은 급박감
- 설사
- 변비
- 방귀·트림
- 메스꺼움
- 구분이 잘 안 됨 ← **이 응답률이 높으면 로깅 UI에서 분리 항목이 성립하지 않는다**

**1-3. 배변 형태** — 브리스톨 척도 (그림 필수) → **아형 추정 (C-1)**
> 최근 2주간 배변이 평소와 달랐던 날, 대변은 주로 어떤 형태였습니까? *(복수 선택)*
> 1형(딱딱한 덩어리) ~ 7형(완전 액체)

**1-4. 로마 IV 기준** — 표본을 IBS 기준 충족/미충족으로 분류. **A-1의 "스펙트럼" 주장 검증용**

> ⚠️ 진단 도구가 아니라 **분류 변수**로만 쓴다. 응답자에게 결과를 통보하지 않는다.

- (a) 최근 3개월간 복통이 평균 주 1일 이상 있었습니까? (예/아니오)
- (b) 그 복통은 배변과 관련이 있었습니까? (예/아니오)
- (c) 복통이 시작될 때 **배변 횟수**가 달라졌습니까? (예/아니오)
- (d) 복통이 시작될 때 **대변 형태**가 달라졌습니까? (예/아니오)
- (e) 이런 증상이 처음 시작된 것이 6개월 이전입니까? (예/아니오)

→ (a)+(e) 충족 & (b)(c)(d) 중 2개 이상 = 기준 충족

**1-5. 레드플래그** *(복수 선택 / 해당 없음)* — **B-1의 실전 리허설 + 윤리적 의무**

- 50세 이후에 처음 시작된 증상
- 혈변 또는 검은 변
- 의도하지 않은 체중 감소
- 자다가 깰 정도의 밤중 통증·설사
- 대장암 / 염증성 장질환 / 셀리악병 가족력
- 빈혈 진단, 원인 모를 발열, 만져지는 배 속 덩어리

> ⚠️ **해당자에게는 설문 종료 페이지에서 반드시 의료기관 상담을 안내한다.**
> 리서치 대상이기 이전에 사람이다. 온보딩 카피 초안을 여기서 미리 테스트할 수 있다.

**1-6. 진단·검사 이력** — **D1의 핵심 데이터**

- 이 증상으로 병원에 간 적이 있습니까? (있음/없음)
- 받은 진단명은? (과민성대장증후군 / 기능성 소화불량 / 위염 / 특별한 이상 없다는 말을 들음 / 기타 / 없음)
- 받은 검사는? *(복수)* (대장내시경 / 위내시경 / 혈액검사 / **셀리악 혈청검사** / 유당불내증 검사 / 없음 / 모름)

> **셀리악 검사 문항이 여기 있는 이유:** B-2. 저포드맵을 시작하면 셀리악 혈청검사가 위음성이 된다.
> 한국에서 이 검사를 받은 사람이 사실상 0에 수렴한다면, 온보딩 게이트를 "검사 여부 확인"이 아니라 **"이 정보를 먼저 알려주기"**로 설계해야 한다. 그 판단을 위한 실측값이다.

**1-7.** "과민성대장증후군"이라는 말을 들었을 때, 본인 이야기라고 느끼십니까? (1 전혀 아니다 ~ 5 매우 그렇다)
→ 1-6의 진단 여부와 교차하면 **D1(진단명 타겟 vs 증상 타겟)이 바로 나온다.**

### §2. 자가 귀인 ⭐ — D2 (이 설문의 심장)

명제 4 "사용자의 자가 귀인은 대부분 틀리다"를 겨냥한다.

**2-1.** *(자유 서술 — 반드시 선택지보다 먼저)*
> 최근 증상이 가장 심했던 날을 떠올려 주세요. **원인이 무엇이었다고 생각하십니까?**

**2-2. ⭐ 핵심 지표**
> 방금 말씀하신 그 원인은, 증상이 나타나기 **얼마나 전**의 일이었습니까?

| 선택지 | 해석 |
|---|---|
| 1시간 이내 / 1–3시간 | **직전 귀인** — 명제 4 성립 |
| 3–6시간 / 6–12시간 | 부분적으로 lag 인식 |
| 12–24시간 / 하루 이상 전 | 명제 4 반증 방향 |
| 잘 모르겠다 | 귀인 실패 — 이것도 앱의 시장이다 |

> **판정 기준:** "3시간 이내" 응답이 **60% 이상**이면 D2 확정, 킬러 메시지(F-3)가 그대로 통한다.
> 30% 이하면 메시지를 다시 짜야 한다.

**2-3.** 그 판단에 얼마나 확신하십니까? (1~5)
→ 확신도가 **높으면서** lag를 짧게 잡는 집단이 앱이 가장 크게 뒤집어줄 수 있는 세그먼트다.

**2-4.** 범인이라고 생각한 음식을 피했는데도 증상이 났던 적이 있습니까? (전혀 없다 ~ 자주 있다, 5점)
→ 사용자가 이미 느끼는 **귀인 실패의 체감량**. 앱의 필요를 사용자 언어로 증명하는 문항.

**2-5.** **같은 음식인데** 어떤 날은 괜찮고 어떤 날은 아팠던 경험이 있습니까? (5점)
→ **C-2 역치·스태킹 모델이 사용자 체감과 맞는지 검증.** 높게 나오면 "왜 같은 양파가 어떤 날은 괜찮은가"가 그대로 마케팅 카피가 된다.

**2-6.** 현재 원인이라고 생각하는 것 *(복수)*
> 우유·유제품 / 밀·빵·면 / 양파·마늘 / 콩류 / 사과·배·수박 / 무설탕 껌·사탕 / 매운 음식 / 기름진 음식 / 커피 / 술 / 탄산음료 / 스트레스 / 잠 부족 / 생리 주기 / 모르겠다

> 앞 6개는 FODMAP, 다음 5개는 비FODMAP 트리거, 나머지는 민감도 계수 축이다.
> **응답 분포가 곧 로깅 항목의 우선순위**가 된다.

### §3. 현재 대처 행동 — D3, D6

**3-1.** 증상 때문에 피하고 있는 음식이 몇 가지입니까? (없음 / 1–2 / 3–5 / 6–10 / 10가지 이상)

**3-2.** 음식을 피하는 것이 일상에 얼마나 불편합니까? (1~5)
- 외식할 때 / 회식·모임 때 / 가족 식사 때 *(각각)*

> **D6:** 한국의 회식 문화가 서구 앱이 다루지 않는 축이다. 회식 항목만 유독 높게 나오면 그 자체로 차별화 지점.

**3-3.** *(자유 서술)* 먹고 싶은데 못 먹고 있는 음식이 있습니까?
→ **명제 3의 확장 도구 포지셔닝을 사용자 언어로 뽑아내는 문항.** 마케팅 카피 원천.

**3-4. 저포드맵 경험** — B-5 검증
- 저포드맵(FODMAP) 식단을 들어본 적 있습니까? (모름 / 들어봄 / 시도함 / 현재 중)
- *(시도자만)* 얼마나 지속했습니까? (1주 미만 / 1–2주 / 3–6주 / **2개월 이상** / 지금도 하는 중)
- *(시도자만)* 중단 이유는? *(복수)* (효과 없음 / 너무 복잡함 / 먹을 게 없음 / 외식 불가 / 증상 좋아져서 / 다음 단계를 몰라서)

> ⚠️ **"2개월 이상" + "지금도 하는 중" 비율이 높으면 B-5가 현실 문제로 확인된다.** 제한 단계에 갇힌 사람들이 실재한다는 뜻이고, "다음 단계를 몰라서"가 중단 이유 상위면 재도입 프로토콜이 곧 제품의 자리다.

**3-5.** 지금까지 시도한 것 *(복수)*
> 유산균 / 병원 처방약 / 약국 약 / 한방 / 식단 조절 / 앱·기록 / 유튜브·블로그 정보 / 아무것도 안 함

**3-6.** 최근 6개월간 이 증상 때문에 실제로 쓴 돈 *(대략)*
> 0원 / 1–5만 / 5–15만 / 15–30만 / 30만 원 이상
→ **§6의 지불의사보다 신뢰도가 높은 실측치.**

### §4. 기록 경험 ⭐ — D4 (리텐션 벽)

**4-1.** 먹은 것이나 증상을 기록해 본 적이 있습니까? (없음 / 있음 — 종이·메모 / 있음 — 앱)

**4-2. ⭐ 핵심 지표** *(기록 경험자만)* 얼마나 지속했습니까?
> 3일 미만 / 3–7일 / 1–2주 / 3–4주 / **1–3개월** / **3개월 이상**

> **판정:** E-1은 "3개월 이상 매일 로깅하는 사용자는 통상 한 자릿수 %"를 전제로 로드맵을 짰다.
> 여기서 1개월 미만이 80% 넘게 나오면 **E-3 로드맵의 "3~6개월 / 200~400건" 구간은 사실상 도달자가 없다**는 뜻이고, 계층적 베이지안(E-4)과 챌린지(E-2)에 더 무게를 실어야 한다.

**4-3.** 중단 이유 *(복수)*
> 귀찮아서 / 기록해도 알게 되는 게 없어서 / 뭘 기록해야 할지 몰라서 / 증상이 좋아져서 / 아픈 날엔 기록할 여유가 없어서 / 앱이 불편해서

> **"아픈 날엔 기록할 여유가 없어서"는 E-6의 비무작위 결측을 직접 재는 문항이다.** 응답률이 높으면 결측이 증상과 상관된다는 뜻이고, 모델에서 결측 처리를 무시할 수 없게 된다.

**4-4.** 하루에 기록에 쓸 수 있는 시간은? (30초 이내 / 1분 / 2–3분 / 5분 이상)
**4-5.** 하루에 알림을 몇 번까지 받아들일 수 있습니까? (0 / 1 / 2 / 3회 이상)

> D-2가 요구하는 **아침 예측 변수 + 증상 시점 결과 변수** 구조는 최소 하루 2회 접점이 필요하다.
> "1회 이하"가 다수면 측정 시각 분리 설계를 UX 차원에서 다시 풀어야 한다.

### §5. 컨셉 반응 — **여기서 처음 컨셉을 노출한다**

**5-1. 메시지 선호** — D3
> 두 앱 중 어느 쪽에 더 끌리십니까?
> **A.** "당신이 피해야 할 음식을 알려드립니다"
> **B.** "당신이 먹을 수 있는 양을 늘려드립니다"
>
> A 훨씬 / A 약간 / 비슷 / B 약간 / B 훨씬 → **이유 자유 서술**

**5-2. 킬러 메시지** — F-3
> "당신 생각과 달리, 범인은 8시간 전 점심일 수 있습니다."
> - 이 말이 놀랍습니까? (1~5)
> - 그럴듯합니까? (1~5)
> - 이런 걸 알려주는 앱이 있다면 써보고 싶습니까? (1~5)

> **놀라움 높음 + 그럴듯함 높음**이 최적. 그럴듯함만 높고 놀라움이 낮으면 이미 아는 얘기라 차별화가 안 된다.

**5-3. ⭐ 챌린지 수용도 — 가장 위험한 문항** — D5
> 앱이 이런 제안을 한다고 해봅시다.
> *"3일간 정해진 양을 순서대로 드셔보세요. 1일차 소량, 2일차 중간, 3일차 다량. 이 기간에는 다른 음식을 조절해야 하고, **증상이 나타날 수 있습니다.** 대신 당신이 이 음식을 어디까지 먹을 수 있는지 정확히 알게 됩니다."*
>
> - 참여할 의향이 있습니까? (1 전혀 없다 ~ 5 매우 있다)
> - *(1~2 응답자)* 가장 큰 이유는? (일부러 아파지기 싫다 / 3일이 부담 / 일정 조율 불가 / 효과를 못 믿겠다 / 기타 자유 서술)
> - 1년에 몇 번까지 할 수 있겠습니까? (0 / 1–2 / 3–5 / 6회 이상)

> ⚠️ **여기서 "의향 낮음"이 다수면 E-2를 전제로 한 전체 모델링 전략이 흔들린다.**
> FODMAP 그룹이 6개인데 연 1~2회밖에 못 한다면 전체 프로필 완성에 3년이 걸린다.
> 그 경우의 대안: ①그룹 우선순위를 §2-6 응답 분포로 정해 1~2개만 챌린지 ②챌린지를 3일에서 단축 ③관찰 데이터 + 강한 사전분포(E-4)로 후퇴.
> **어느 쪽이든 지금 알아야 하는 정보다.**

**5-4. 역치 프로필** — F-1
> *(6축 레이더 차트 목업 제시)* "락토스는 괜찮은데 폴리올만 약하다"처럼 종류별로 내 한계치를 보여주는 화면입니다.
> - 이해되십니까? (1~5)
> - 매력적입니까? (1~5)

**5-5. 라벨 반응** — D1
> 어느 쪽 소개가 더 와닿습니까?
> **A.** "과민성대장증후군 관리 앱"
> **B.** "먹고 나면 배가 아픈 사람을 위한 앱"

→ **§1-6(진단 여부)과 교차분석.** 미진단자에서 B 선호가 뚜렷하면 A-1 확정.

### §6. 지불 의사 — D7

Van Westendorp 4문항. 단일 가격 제시보다 수용 가격대를 넓게 잡아준다.
**"월 구독"임을 명시**하고 물을 것.

- (a) 어느 가격부터 **너무 비싸서** 구매를 고려하지 않겠습니까?
- (b) 어느 가격부터 **비싸다**고 느끼지만 고려는 해보겠습니까?
- (c) 어느 가격이면 **저렴하다**고 느끼겠습니까?
- (d) 어느 가격 이하면 **너무 싸서** 품질이 의심스럽겠습니까?

추가: 월 구독 / 연 구독 / 1회 결제 중 선호 형태

> §3-6(실제 지출)과 교차하면 응답의 신빙성을 검증할 수 있다. 지출 0원인데 고가를 답한 응답은 할인해서 본다.

### 최소 표본

| 분석 목적 | 필요 n |
|---|---|
| 전체 비율 추정 (±7%p) | 200 |

### 모집 경로와 편향 ⚠️

| 경로 | 편향 |
|---|---|
| IBS 커뮤니티·카페 | **중증 편향.** 이미 진단받고 정보 탐색 중인 사람 → D1이 왜곡됨 |

## 5. 설문으로는 검증되지 않는 것 ⚠️

정직하게 선을 그어둔다.

| 검증 불가 | 이유 | 대안 |
|---|---|---|
| **자가 귀인이 실제로 틀렸는가** | 설문은 사용자가 **뭘 믿는지**만 잰다. 진위는 실제 식이·증상 로그와 대조해야 안다 | 소규모 2주 다이어리 스터디 (n=10~20) |
| 실제 리텐션 | 의향과 행동은 다르다 | 랜딩페이지 + 프리토타입 |
| 실제 결제 | 동일 | 사전예약 결제 테스트 |
| 챌린지 완주율 | §5-3은 의향일 뿐 | 파일럿에서 실측 |
| lag의 생리학적 값 | 애초에 사용자에게 물을 것이 아님 (C-4: 코드가 아니라 생리학이 정한다) | — |

**설문이 줄 수 있는 최대치는 "사용자가 lag를 3시간 이내로 인식한다"까지다.**
그것만으로도 킬러 메시지의 근거로는 충분하다. 명제 4의 완전한 증명은 로그가 쌓여야 가능하고, 그건 제품 자체가 하는 일이다.
