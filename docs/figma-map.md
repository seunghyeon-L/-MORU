## 1. A1 서비스 소개

- **화면 목적**: 서비스 소개 + "의료 서비스가 아님" 안내, 온보딩 진입
- **주요 UI**: MORU 로고/일러스트, 헤드카피, 1·2·3 소개 카드(사진 기록/패턴 분석/재도입), 하단 면책 문구, CTA 버튼 1개
- **사용자 입력**: 버튼 탭(시작하기) 외 없음
- **다음 화면**: B1 온보딩 · 안전 확인
- **Figma 식별 특징**: 프레임명 "A1 서비스 소개". "두려움 때문에 좁아진 식탁..." 헤드카피, "시도한 사람의 71%가 되찾았어요" 문구, 하단에 버튼 컴포넌트(`Button (auto-pressed) - Frame`) 1개
- **별도 route 필요 여부**: 예
- **필요한 주요 state**: 없음 (정적 화면)
- **현재 Expo Router route**: `/` (`src/app/index.tsx`)
- **추가해야 할 route**: 없음

## 2. B1 온보딩 · 안전 확인

- **화면 목적**: 위험 신호(레드플래그) 자가 체크. AI 판정 아님, 규칙 기반 분기
- **주요 UI**: 진행 표시 "1/4", 질문 헤드라인, 체크리스트(변에 피, 원인 모를 체중감소, 복통·설사, 발열, 구토, 빈혈, 50세 이후 신규 증상), CTA 2개
- **사용자 입력**: 다중 선택 체크박스
- **다음 화면**: 해당 항목 있음 → B1x, 없음 → B2
- **Figma 식별 특징**: 진행바 "1 / 4", "먼저 확인할게요" 타이틀, 7개 항목 리스트, 버튼 2개(있음/없음)
- **별도 route 필요 여부**: 예
- **필요한 주요 state**: 선택된 체크리스트 항목(로컬 state)
- **현재 Expo Router route**: `/onboarding/safety`
- **추가해야 할 route**: 없음

## 3. B1x 안전 · 병원 안내 (차단)

- **화면 목적**: 위험 신호가 있을 때 병원 상담 안내, 서비스 진입 차단
- **주요 UI**: 경고 헤드라인 "먼저 병원에서 확인해주세요", 선택했던 항목 표시, "가까운 병원 찾아보기" 버튼, 진행 계속 옵션

- **별도 route 필요 여부**: 예

- **별도 route 필요 여부**: 아니오 — 홈/기록 탭에서 뜨는 바텀시트이므로 별도 화면이 아니라 해당 탭 화면의 state(모달 열림 여부)로 처리

- **현재 Expo Router route**: 없음 (현재는 기록 탭 카드에서 `/food/camera`, `/food/search`로 바로 이동)
